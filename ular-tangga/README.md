# Ular Tangga Edukasi

Game web statis: guru/siswa membuat papan, ular, tangga, dan bank soal sendiri. Saat bidak mendarat di kotak bersoal (atau di finish), pemain harus menjawab dulu.

**Alamat:** https://yusuffirmansyah2310-max.github.io/informatika/ular-tangga/

## Cara pakai
1. Buka alamat di atas. Atur judul, tema, papan, pemain, ular/tangga, soal, dan aturan.
2. Klik **MULAI GAME**. Kocok dadu dengan klik atau Spasi.
3. Simpan konfigurasi sebagai JSON untuk dibagikan; muat kembali lewat **Muat konfigurasi**.

## Deploy
Unggah folder `ular-tangga/` ke repo `informatika` (jangan menimpa `index.html` di root), aktifkan Settings → Pages (branch `main`, folder `/ (root)`).

Catatan: halaman memakai ES Modules, jadi harus dibuka lewat GitHub Pages atau server lokal (mis. `python -m http.server`), bukan klik dua kali dari file.
